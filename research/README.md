# Research

このディレクトリは、Sado Investment Labにおける市場分析・投資仮説・検証結果を蓄積するための研究領域です。

## 目的

日々の相場観を感覚だけで終わらせず、株価データと実際の売買履歴を用いて再現性を検証します。

主な研究対象は次のとおりです。

- テーマごとの値動き、波長、位相差
- 銘柄間の相関とクラスタ分類
- 先行銘柄・遅行銘柄の探索
- テーマ間の資金ローテーション
- 利確後の資金移動と、その後の成績
- 急落時の買い判断と現金比率の検証

## Sado Market Phase Analyzer（SMPA）

最初の研究プロジェクトとして、AI半導体エコシステムを対象に以下を分析します。

1. 候補銘柄の日足データ取得
2. 日次リターンの相関分析
3. 値動きの近い銘柄の自動クラスタ分類
4. 先行・遅行関係の検証
5. 上昇・調整周期の基礎分析
6. 分析結果に基づく独自テーマ指数の生成
7. 実際の売買履歴を重ねた資金ローテーション分析

## 方針

- 事実と推測を区別する
- 相関を因果関係と断定しない
- 単一期間だけで結論を出さず、複数期間で再現性を確認する
- 分析に必要な銘柄名、価格、数量、損益は原則として匿名化しない
- 住所、口座番号、認証情報など、投資分析に不要な個人情報は保存しない
