# Actual Data Validation

実データはローカル環境だけで処理し、CSV、SQLite、個別取引、損益額は公開していません。

## 技術検証

- 約定明細1,550件をエラーなく登録
- 同じCSVの再取込で1,550件すべてを重複としてスキップ
- 対象期間: 2024-07-18〜2026-07-31
- 銘柄コード数: 128
- FIFO決済ロット数: 718
- 未対応約定数: 124

未対応約定には、対象期間より前に建てたポジションの決済、対象期間より前に取得した
現物・投資信託の売却、期間末時点の未決済建玉が含まれます。

## 損益の方針

確定損益にはSBI記載の決済損益を優先します。FIFOは保有期間と売買傾向の推定に利用
します。実際の建玉指定、株式分割、手数料・諸経費の扱いによって、FIFOの価格差計算と
証券会社の確定損益には差異が生じ得ます。

この文書は件数と処理方針のみを公開し、具体的な利益額、総取引金額、資産額、口座情報、
現在の詳細保有数量、元CSVの行データを含みません。
