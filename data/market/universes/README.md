# Market Phase Universes

Market Phase分析で使用する銘柄集合を、分析コードから分離して管理する。

## 構成

- `catalog.json`: 利用可能なユニバースと分析レイヤーの一覧
- `ai-semiconductor-40.json`: Layer 1。既存のAI半導体分析
- `ai-ecosystem-v1.json`: Layer 2。AI需要の産業間波及を観察する初期設計

## 銘柄スキーマ

Layer 2の銘柄には、銘柄コード、名称、主分類、役割、採用理由を記録する。

一つの銘柄を複数の指数へ重複計上しないよう、`category`は一つにする。複数の産業に関係する場合は`roles`で表現する。

カテゴリーを追加する時は、`category_order`へ名称を追加した後、該当銘柄の主分類として使用する。分析処理は固定のカテゴリー名へ依存させない。

銘柄採用は投資推奨を意味しない。価格データの取得可否、流動性、事業構成、テーマ感応度を確認し、定期的に見直す。
