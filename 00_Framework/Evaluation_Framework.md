# Evaluation Framework

## Rating Scale

★★★★★ 非常に強い / ★★★★☆ 強い / ★★★☆☆ 標準 / ★★☆☆☆ 注意 / ★☆☆☆☆ 高リスク

| 評価項目 | 評価 | 確認する内容 |
|---|---|---|
| 競争優位 | 未評価 | 技術、ブランド、顧客、コスト |
| 参入障壁 | 未評価 | 設備、認証、ノウハウ、切替コスト |
| 売上成長 | 未評価 | 市場成長、シェア、価格、数量 |
| 利益率 | 未評価 | 営業利益率、改善余地 |
| キャッシュ創出力 | 未評価 | 営業CF、FCF |
| 財務健全性 | 未評価 | 現金、負債 |
| 経営・資本配分 | 未評価 | 投資、還元、M&A |
| AI恩恵 | 未評価 | 直接・間接恩恵と時間軸 |
| 中国リスク | 未評価 | 売上、調達、競争、規制 |
| 市場期待 | 未評価 | コンセンサスと織り込み |
| 期待値 | 未評価 | 上昇・下落余地と確率 |
