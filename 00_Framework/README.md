# Framework

Kohei Investment Labの投資判断を支える、長期的な思想・原則・評価方法をまとめるディレクトリです。

## Files

- [Investment_Philosophy.md](Investment_Philosophy.md): 長期的に変わらない投資思想
- [Investment_Rules.md](Investment_Rules.md): 売買とリスク管理のルール
- [Market_Psychology.md](Market_Psychology.md): 市場参加者の期待、恐怖、需給の理解
- [Thinking_Process.md](Thinking_Process.md): 分析から判断までの思考手順
- [Evaluation_Framework.md](Evaluation_Framework.md): 企業を評価する共通の物差し
- [Lessons_Learned.md](Lessons_Learned.md): 投資から得た再利用可能な教訓

## Usage

1. 投資判断の前に思想とルールを確認する
2. 企業価値と市場心理を分けて分析する
3. Thinking Processに沿って事実・解釈・仮説を整理する
4. Evaluation Frameworkで同じ基準から評価する
5. 結果をLessons Learnedへ戻し、Frameworkを育てる
