# SBI Trade Import Specification

## 目的

SBI証券の約定履歴CSVを非公開領域からSQLiteへ安全かつ再現可能に取り込み、
売買履歴の統計分析とSado Frameworkの検証に利用する。

## 入力

- SBI証券「約定履歴照会」のCSV
- 文字コードはCP932またはUTF-8
- 検索条件や注記を含む場合、`約定日`と`銘柄`を持つ明細ヘッダーを自動検出する
- 銘柄コードは英字を含み得るため文字列として保存する
- 元CSVは`data/private/`に置き、Gitへ登録しない

## SQLite

`executions`、`closed_trades`、`unmatched_executions`を作成する。約定の正規化値と
同一内容の出現順からSHA-256指紋を生成し、同じCSVの再取込を冪等にする。同一CSV内の
同内容約定は別約定として保持する。

## 対応付け

現物・信用買建は買いから売り、信用売建は売りから返済買へFIFOで対応付ける。
部分決済は数量単位で分割する。取得期間外の建玉や期間末の未決済建玉は
`unmatched_executions`へ理由付きで残す。

## 損益

SBI CSVの`受渡金額/決済損益`にある信用決済損益を確定損益の正とする。FIFOによる
価格差損益は保有期間や売買傾向の推定用である。建玉指定、株式分割、手数料・諸経費の
扱いにより両者は一致しない場合がある。

## 出力と安全性

生成DBは`data/database/`、レポートは`data/generated/`へ保存し、いずれもGit管理外と
する。公開可能なのはスクリプト、仕様、匿名化した検証結果、テストのみとする。
